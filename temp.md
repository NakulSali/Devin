Here is a complete, step-by-step guide to creating a basic Express server.\n\n### Step 1: Initialize your project\nOpen your terminal and run the following commands to create a new folder, navigate into it, and initialize a Node.js project:\n\n```bash\nmkdir my-express-server\ncd my-express-server\nnpm init -y\n```\n*(The `-y` flag automatically answers \"yes\" to all the default setup questions).*\n\n### Step 2: Install Express\nInstall the Express package via npm:\n\n```bash\nnpm install express\n```\n\n### Step 3: Create the server file\nCreate a file named `index.js` (or `server.js`) in your project root folder. \n\nIf you are on Mac/Linux:\n```bash\ntouch index.js\n```\nIf you are on Windows (PowerShell):\n```bash\nNew-Item index.js\n```\n\n### Step 4: Write the Express code\nOpen `index.js` in your code editor (like VS Code) and paste the following code:\n\n```javascript\nconst express = require('express');\nconst app = express();\nconst PORT = process.env.PORT || 3000;\n\n// Middleware to parse JSON bodies (useful for POST requests)\napp.use(express.json());\n\n// Define a basic GET route\napp.get('/', (req, res) => {\n  res.send('Hello World! Your Express server is running.');\n});\n\n// Define another route (e.g., an API endpoint)\napp.get('/api/info', (req, res) => {\n  res.json({\n    status: 'success',\n    message: 'Welcome to the API',\n    timestamp: new Date()\n  });\n});\n\n// Start the server\napp.listen(PORT, () => {\n  console.log(`Server is running on http://localhost:${PORT}`);\n});\n```\n\n### Step 5: Run your server\nGo back to your terminal and run:\n\n```bash\nnode index.js\n```\n\nYou should see this message in your terminal:\n> `Server is running on http://localhost:3000`\n\n### Step 6: Test it\n1. Open your web browser and go to: `http://localhost:3000`\n   * You should see: **\"Hello World! Your Express server is running.\"**\n2. Go to: `http://localhost:3000/api/info`\n   * You should see the JSON data response.\n\n---\n\n### Pro Tip: Use `nodemon` for development\nBy default, if you make changes to `index.js`, you have to stop the server (`Ctrl + C`) and restart it. To automate this:\n\n1. Install `nodemon` as a development dependency:\n   ```bash\n   npm install --save-dev nodemon\n   ```\n2. Open your `package.json` file and add a start script:\n   ```json\n   \"scripts\": {\n     \"start\": \"node index.js\",\n     \"dev\": \"nodemon index.js\"\n   }\n   ```\n3. Now, you can run your server with:\n   ```bash\n   npm run dev\n   ```\n   The server will now automatically restart whenever you save changes to your code!"
